Implement `KCHValidator` in `src/quality/ast_validator/validator.py`:

```python
@dataclass
class Violation:
    file: str
    line: int
    severity: str  # "CRITICAL", "WARNING", "INFO"
    violation_type: str  # "PHANTOM_FUNCTION", "WRONG_PARAMETER", "PHANTOM_IMPORT", "DEPRECATED_API"
    message: str
    suggestion: str | None = None

class KCHValidator:
    def __init__(self, stub_dir: Path) -> None: ...
    def validate_file(self, file_path: Path) -> list[Violation]: ...
    def validate_directory(self, dir_path: Path) -> list[Violation]: ...
```

The validator loads all `*_stubs.py` files from `stub_dir`. Each stub file defines a dict mapping `library_name -> {module -> {function_name -> set_of_valid_kwargs}}`. The validator compares extracted calls against this ground truth.

For wrong parameter suggestions, use `difflib.get_close_matches(wrong_kwarg, valid_kwargs, n=1, cutoff=0.6)`.

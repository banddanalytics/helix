Implement `PiTValidator` in `src/quality/pit_validator.py` per D-17:

The validator uses AST inspection to detect look-ahead bias. It walks the AST looking for assignment expressions where the right-hand side accesses price-related columns (price, volume, bid, ask, close, high, low, open, returns, spread) without a `.shift()` call in the chain.

```python
from __future__ import annotations
import ast
from dataclasses import dataclass
from pathlib import Path

PRICE_COLUMNS: frozenset[str] = frozenset({
    "price", "volume", "bid", "ask", "close", "high", "low", "open",
    "returns", "spread", "tick_volume",
})

@dataclass
class PiTViolation:
    file: str
    line: int
    column_accessed: str
    expression: str
    message: str

class PiTValidator(ast.NodeVisitor):
    def __init__(self) -> None:
        self.violations: list[PiTViolation] = []
        self._current_file: str = ""

    def validate_file(self, file_path: Path) -> list[PiTViolation]: ...
    def validate_directory(self, dir_path: Path, pattern: str = "**/*.py") -> list[PiTViolation]: ...
```

Detection logic: For each `ast.Assign` or `ast.AugAssign` node, walk the value subtree. If a `ast.Subscript` accessing a known price column name (string literal in the subscript slice) appears, check whether `.shift()` is called on the chain. If no `.shift()` found, record a violation.

Also detect `.rolling().agg()` and `.rolling().std()` patterns without a subsequent `.shift()`.

Create `scripts/pit_validator.py` CLI:
- Accepts `--source` argument (directory to scan, default `src/alpha/`)
- Runs PiTValidator.validate_directory()
- Outputs violations as JSON
- Exits 0 if clean, 1 if any violation

Write tests FIRST (red phase), covering all 4 cases from the behavior spec, then implement to pass.

Create `.pre-commit-config.yaml` per D-07, D-08, D-09, D-10.

Per D-07: Pre-commit runs ONLY ruff (lint + format) and mypy. Target under 10 seconds.
Per D-08: pytest and coverage do NOT run in pre-commit.
Per D-09: AST/KCH and PiT validators do NOT run in pre-commit (CI only).

```yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v5.0.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-toml

  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.15.7
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format

  - repo: local
    hooks:
      - id: mypy
        name: mypy strict
        entry: .venv/bin/mypy
        language: system
        types: [python]
        args: [--strict]
        pass_filenames: true
```

NOTE: Use `repo: local` with `language: system` for mypy to use the project venv's mypy (avoids pre-commit creating its own venv without project deps). Do NOT use `mirrors-mypy` repo since it would need all project dependencies duplicated in `additional_dependencies`.

After creating the config, run:
```bash
.venv/bin/pre-commit install
.venv/bin/pre-commit run --all-files
```

Create `.github/workflows/ci.yml` per D-11, D-12, D-13, D-14.

CI gate order per D-11: static analysis → AST/KCH → PiT → unit tests → coverage.
Per D-12: `--cov-fail-under=80`.
Per D-13: `ubuntu-latest` only, no Windows runner.
Per D-14: File at `.github/workflows/ci.yml`.

```yaml
name: Helix CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  static-analysis:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
          cache: 'pip'
      - run: pip install -r requirements-dev.txt
      - name: Ruff lint and format check
        run: ruff check . && ruff format --check .
      - name: mypy strict
        run: mypy src/ --strict
      - name: AST/KCH validation
        run: python scripts/ast_validator.py --stubs stubs/ --source src/
      - name: PiT compliance check
        run: python scripts/pit_validator.py --source src/alpha/

  tests:
    needs: static-analysis
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
          cache: 'pip'
      - run: pip install -r requirements-dev.txt
      - name: Run tests with coverage
        run: pytest tests/ --cov=src --cov-report=xml --cov-report=term-missing --cov-branch --cov-fail-under=80 -v
      - name: Upload coverage
        uses: codecov/codecov-action@v4
        with:
          file: coverage.xml
        if: always()

  e2e:
    needs: tests
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
          cache: 'pip'
      - run: pip install -r requirements-dev.txt
      - name: Run e2e tests
        run: pytest tests/e2e/ -v --timeout=300
```

Implement the regime recalibration scheduler with weekly Baum-Welch refitting, GARCH parameter updates, Dirichlet smoothing, and two-gate validation (stationarity + state agreement) before model hot-swap.

Purpose: The regime detector must adapt to evolving market conditions. Without recalibration, regime labels drift from reality over weeks. The two-gate validation prevents bad refits from corrupting the live regime state.
Output: RecalibrationService that refits the HMM-GARCH model weekly with safe atomic swap.
</objective>

    2. Create `src/alpha/regime/calibration.py`:
       - `import yaml`, `import logging`, `from pathlib import Path`
       - `logger = logging.getLogger("helix.alpha")`
       - Class `RecalibrationService`:
         - `__init__(self, detector: HMMGARCHRegimeDetector, config_path: str = "config/regime_calibration.yaml")`:
           - Stores reference to current detector
           - Loads config from YAML
           - `self._pending: HMMGARCHRegimeDetector | None = None`
           - `self._last_params: list[GARCHParams] | None = None` (for drift comparison)
         - `recalibrate(self, returns: np.ndarray) -> bool`:
           - Create new `HMMGARCHRegimeDetector` instance
           - Call `new_detector.fit(returns)` — if False, log and return False
           - Apply Dirichlet smoothing to `new_detector.transmat_`:
             `smoothed = transmat + concentration` then row-normalize
           - **Gate 1 — Stationarity:** Check `all(p.is_stationary for p in new_detector.garch_params)`. If fails, reject.
           - **Gate 2 — State agreement:** If `self._detector.is_fitted`:
             - Run `old_states = self._detector.predict_viterbi(returns[-100:])`
             - Run `new_states = new_detector.predict_viterbi(returns[-100:])`
             - `agreement = np.mean(old_states == new_states)`
             - If `agreement < 0.90`, reject with log
           - **Drift warning:** Compare each GARCHParams field to `self._last_params`:
             - For each (old, new) pair: `drift = abs(new - old) / max(abs(old), 1e-10)`
             - If any drift > 0.50: `logger.warning("Parameter drift >50%: ...")` but do NOT reject
           - On success: set `self._pending = new_detector`, update `self._last_params`
           - Return True
         - `apply_pending(self) -> bool`:
           - If `self._pending` is not None, swap: `self._detector = self._pending`, `self._pending = None`, return True
           - Else return False
         - `has_pending -> bool` property
         - `@property detector -> HMMGARCHRegimeDetector`: returns current active detector

    3. Update `src/alpha/regime/__init__.py` to export `RecalibrationService`

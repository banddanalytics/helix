Build the 5-tier, 27-feature Numba pipeline for ML price momentum: momentum (8), volatility (6), session (5), cross-asset (4), tick volume (4). Register Numba functions in warmup.py. Assemble all features via FeatureBuilder with PiT .shift(1) compliance.

Output: 27 PiT-compliant features compilable under Numba (except Tier 4), assembled by FeatureBuilder.
</objective>

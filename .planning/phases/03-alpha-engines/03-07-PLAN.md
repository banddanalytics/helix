Build the walk-forward XGBoost+RF ensemble with SHAP analysis: model wrappers, 756-bar/21-step walk-forward engine, 50/50 ensemble, cost-adjusted metrics, and per-window SHAP feature importance tracking.

Purpose: The ML momentum engine is one of two Trending-regime strategies. Walk-forward validation prevents overfitting by training on rolling windows and testing on unseen data. SHAP provides interpretability — understanding which features drive predictions and detecting regime shifts.
Output: Complete walk-forward pipeline producing OOS predictions with SHAP analysis.

         - `run(self, X: np.ndarray, y: np.ndarray, feature_names: list[str] | None = None) -> list[WindowResult]`:
           - Total windows: `(len(X) - train_window - purge_gap - test_window) // step + 1`
           - For each window w:
             - `train_end = train_window + w * step`
             - `train_start = train_end - train_window`

             - `test_end = test_start + test_window`
             - `X_train, y_train = X[train_start:val_start], y[train_start:val_start]`
             - `X_val, y_val = X[val_start:train_end], y[val_start:train_end]`

Implement the RegimeOrchestrator that owns all strategy activation based on regime state, with 20-bar hysteresis dwell logic, CrossAssetCache for ML features, and ArcticDB signal persistence.

Purpose: The orchestrator is the central coordinator that ties all four engines together. It reads the regime state, decides which engines to call, collects their signals, and persists everything to ArcticDB. Without it, the individual engines have no coordination or regime gating.
Output: Working RegimeOrchestrator that gates strategies by regime, enforces hysteresis, and writes signals to ArcticDB.

         - `__init__(self, regime_filter: OnlineRegimeFilter, calibration_service: RecalibrationService, engines: dict[str, object], cache: CrossAssetCache | None = None)`:
           - `self._regime_filter = regime_filter`
           - `self._calibration = calibration_service`
           - `self._engines = engines` — `{"ml_engine": MLEngine, "carry_engine": CarryEngine, "cointegration_engine": CointEngine}`
           - `self._cache = cache`
           - `self._current_regime: RegimeState = RegimeState.TRENDING` (default)
           - `self._regime_confidence: float = 0.0`
           - `self._dwell_counter: int = 0`
           - `self._hysteresis_bars: int = 20`
           - Regime switch thresholds (per spec):
             - `self._enter_thresholds = {RegimeState.TRENDING: 0.70, RegimeState.MEAN_REVERTING: 0.65, RegimeState.CRISIS: 0.60}`
             - `self._exit_threshold: float = 0.30`

         - `def on_bar(self, symbol: str, bar_return: float, bar_data: dict | None = None) -> list[SignalRow]`:
           - **Step 0:** Apply pending model if available: `if self._calibration.has_pending: self._calibration.apply_pending(); self._regime_filter.reset()`
           - **Step 1:** Update regime: `new_regime, confidence = self._regime_filter.update(bar_return)`
           - **Step 2:** Hysteresis check:
             - `self._dwell_counter += 1`
             - If `self._dwell_counter < self._hysteresis_bars`: keep current regime (ignore new_regime)
             - Else: check thresholds — enter new state only if `confidence > enter_threshold[new_regime]` AND current state `confidence < exit_threshold`
             - On regime change: `self._current_regime = new_regime`, `self._dwell_counter = 0`
           - **Step 3:** Get active engines: `active = REGIME_ACTIVATION[self._current_regime]`
           - **Step 4:** For each active engine name, call `self._engines[name].generate_signals(symbol, bar_data)`
           - **Step 5:** Collect signals, tag with `regime=self._current_regime.value`
           - Return collected signals (empty list if CRISIS)

         - `async def persist_signals(self, signals: list[SignalRow], symbol: str) -> None`:
           - Group signals by engine
           - For each group: create DataFrame from SignalRows
           - Write to ArcticDB: `lib = get_library("signals")`, symbol pattern `{engine}_{symbol}`
           - Use try/except pattern: `lib.append()` first, fall back to `lib.write()` (per Pitfall 6)
           - Also write regime state: `lib.write("regime_{symbol}", regime_df)` or append

         - `async def persist_regime_state(self, symbol: str, timestamp: pd.Timestamp) -> None`:
           - Create single-row DataFrame with timestamp, regime, confidence
           - Write to `regime_{symbol}` in signals library (per D-03)

         - Property `current_regime -> RegimeState`
         - Property `dwell_counter -> int`

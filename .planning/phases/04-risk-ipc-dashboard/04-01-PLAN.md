    - compute_cvar_parametric: given mu=0.001, sigma=0.02, alpha=0.95, returns (var, cvar) computed from normal distribution: var = -(mu - z*sigma), cvar = -(mu - sigma*norm.pdf(z)/(1-alpha)) where z=norm.ppf(0.95)
    - compute_cvar_parametric: returns tuple of two positive floats when mu is small relative to sigma
    - compute_cvar_cornish_fisher: given a skewed return series, adjusts the z-quantile for skewness and kurtosis using z_cf = z + (z^2-1)*skew/6 + (z^3-3*z)*kurt/24 - (2*z^3-5*z)*skew^2/36
    - compute_cvar_cornish_fisher: when returns have zero skew and zero excess kurtosis, result converges to parametric CVaR
    - compute_cvar_cornish_fisher: when tail subset is empty (no returns below threshold), cvar fallback = var * 1.2

       - Compute `mu, sigma = np.mean(returns), np.std(returns)`

       - `tail = returns[returns <= -(var)]` — returns below the VaR threshold
       - `cvar = -tail.mean() if len(tail) > 0 else var * 1.2`
       - Return `(var, cvar)`

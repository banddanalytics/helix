## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding, inline dividers |
| sm | 8px | Compact table cell padding, chip spacing |
| md | 16px | Default card padding, form field spacing |
| lg | 24px | Section padding, card gap in grid |
| xl | 32px | Layout column gaps, route-level vertical padding |
| 2xl | 48px | Major section breaks between dashboard panels |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Touch targets for any interactive icon button: minimum 44px (WCAG 2.5.5 compliance)
- Status indicator dot: 8px × 8px fixed (uses xs token for margin, not the dot itself)

Source: 8-point grid default; exceptions from accessibility standard.

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Display | 28px | 600 (semibold) | 1.2 | Geist Sans | Page headings, route titles |
| Heading | 20px | 600 (semibold) | 1.2 | Geist Sans | Panel headings, section labels |
| Body | 16px | 400 (regular) | 1.5 | Geist Sans | Descriptions, alert messages, tooltips |
| Label | 14px | 400 (regular) | 1.4 | Geist Mono | Table cells, numeric values, status text, axis ticks |

Rules:
- All numeric data (PnL, CVaR, z-scores, equity, drawdown %) MUST use Geist Mono at 14px weight 400.
- Do NOT use weights other than 400 and 600.
- Do NOT add a 5th type size. Route titles use Display (28px); panel sub-headings use Heading (20px).

Source: Default; Geist Mono for numeric data is standard for trading terminal aesthetics per CONTEXT.md D-03.

## Color

All colors are dark-mode only. No light mode. (Source: CONTEXT.md — "Dark trading terminal aesthetic. No light mode." + Deferred: "Light mode for dashboard — out of scope.")

| Role | Tailwind Token | Approximate Hex | Usage |
|------|---------------|-----------------|-------|
| Dominant (60%) | `zinc-950` | `#09090b` | Page background, primary surface |
| Secondary (30%) | `zinc-900` | `#18181b` | Cards, sidebar, nav rail, table rows |
| Accent (10%) | `cyan-400` | `#22d3ee` | See reserved list below |
| Destructive | `red-500` | `#ef4444` | Circuit breaker L2/L3 indicators, flatten-all actions, error states |

**Accent (`cyan-400`) reserved exclusively for:**
1. Active navigation item highlight (current route indicator)
2. Positive PnL delta indicator (equity curve line, PnL sparkline)
3. Regime state badge — "Trending" state only
4. Primary CTA button fill (e.g., "Restart Trading" manual restart action)
5. Chart line for live/real-time data series

**Semantic color additions (beyond destructive):**
- Warning: `amber-400` (`#fbbf24`) — Circuit breaker L1 indicator, sandboxed strategy badge
- Muted: `zinc-600` (`#52525b`) — Disabled states, zero-value cells, "— " placeholder text
- Neutral-positive: `emerald-400` (`#34d399`) — Regime "Mean-Reverting" state badge, recovery bar progress

Source: D-03 (dark terminal aesthetic). Specific accent reservations are designer discretion per CONTEXT.md "Claude's Discretion."

## Data States

Every panel that receives live data MUST implement all four states:

| State | Behavior |
|-------|----------|
| Loading | `<Skeleton>` matching panel dimensions, shown while WebSocket connects or `<Suspense>` pending |
| Connected / Live | Normal data display with cyan "LIVE" dot in panel header |
| Stale | Amber "STALE" badge when last update > 2× expected interval (e.g., PnL stale after 200ms) |
| Error | `<ErrorBoundary>` catches → shows error card with message + "Retry connection" link; does NOT crash sibling panels |

Source: IPC-04, IPC-06 (REQUIREMENTS.md); D-05 error boundary isolation (CONTEXT.md).

## Real-Time Update Throttle

`useNatsSubscription` hook MUST buffer messages and batch React state updates at 100ms intervals to prevent re-render thrash (IPC-06). Do not call `setState` on every incoming message.

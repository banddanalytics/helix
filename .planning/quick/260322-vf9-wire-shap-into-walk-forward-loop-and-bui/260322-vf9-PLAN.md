**Create `scripts/validate_pipeline.py`:**

A standalone script (runnable via `python scripts/validate_pipeline.py`) that exercises the full pipeline. Structure:

```python
"""End-to-end Helix pipeline validation — Yahoo Finance → metrics.

No ArcticDB dependency. Uses vbt.YFData.pull() for data sourcing.
Run: python scripts/validate_pipeline.py [--pairs EURUSD GBPUSD] [--months 18]
"""
```

**Pipeline steps:**

1. **Data pull** — `vbt.YFData.pull(symbols=["EURUSD=X", "GBPUSD=X"], start="2024-09-22", end="2026-03-22", timeframe="1h", tz="UTC")`. Default to EURUSD=X and GBPUSD=X. Accept `--pairs` CLI arg via argparse to override.

2. **Per-symbol loop:**

   a. Extract arrays: `open_arr = ohlc["Open"].values`, `high = ohlc["High"].values`, etc. `tick_volume = ohlc["Volume"].values` (will be 0 for FX — acceptable).

   b. **Regime detection** — `log_returns = np.log(close / np.roll(close, 1))[1:]`. Fit `HMMGARCHRegimeDetector()`. Call `predict_viterbi(log_returns)`. Print regime distribution (`np.bincount`).

   c. **Feature building** — Build cross_asset_data dict from all symbols' close prices. `FeatureBuilder(cross_asset_data).build(symbol, open_arr, high, low, close, tick_volume, hour, dow)`. `hour = pd.DatetimeIndex(ohlc.index).hour.values`, `dow = pd.DatetimeIndex(ohlc.index).dayofweek.values`.

   d. **Label generation** — `y = (pd.Series(close).shift(-1) > close).astype(int).values`. Drop last row (NaN label).

   e. **NaN warmup drop** — `valid_mask = ~np.isnan(features_df.values).any(axis=1)`. Slice X, y to valid rows. Expect first ~254 rows dropped.

   f. **Walk-forward** — `WalkForwardEngine(WalkForwardConfig()).run(X, y, FeatureBuilder.FEATURE_NAMES)`.

   g. **SHAP stability** — Collect `shap_result` dicts from WindowResults, call `SHAPAnalyzer.track_stability()`. Print stable features.

   h. **Signal generation** — For each window, generate signals from predictions using `EnsembleModel().generate_signal()` per bar.

   i. **Backtest** — Compute ATR (14-bar rolling range proxy): `atr = pd.Series(high - low).rolling(14).mean().values`. Call `single_pass_backtest(close_test, signal_arr, risk_per_trade=0.01, atr_test, spread_cost_arr)`. Spread cost = `np.full(n, 0.00012)` for EURUSD, `np.full(n, 0.00015)` for GBPUSD.

   j. **Metrics** — Compute and print: gross_sharpe, cost_adjusted_sharpe (bars_per_year=6048), max drawdown, win rate, profit factor, num trades.

3. **Cost sensitivity sweep** — For each symbol, sweep `multipliers = [0.5, 1.0, 1.5, 2.0, 3.0, 5.0]` × base spread. Run backtest per multiplier. Print table: `multiplier | Sharpe | MaxDD | ProfitFactor`. This is the key Tier 4 validation.

4. **Cross-pair correlation** — If ≥2 symbols, compute pairwise Pearson correlation of OOS prediction arrays (truncate to shortest). Print correlation matrix.

5. **Output** — All results printed to stdout in formatted tables. Use f-strings and alignment, no external table library needed. Exit 0 on success.

**Robustness:**
- Wrap `vbt.YFData.pull()` in try/except with clear error message about network/Yahoo Finance availability.
- If HMMGARCHRegimeDetector.fit() returns False, log warning and use uniform regime (all state 0) as fallback.
- Mark the script with `if __name__ == "__main__":` guard.
